# Cavalo Finance App

Vercel-ready React/Vite iPhone web app.

## Deploy
Upload this folder or ZIP to Vercel.
Build command: npm run build
Output directory: dist

## Includes
- Cavalo-style mobile UI
- Full repayment calculator logic
- Lender buttons for VWFS and Pepper Commercial
- Hidden send/share panel in bottom nav
- PDF quote download
- SMS and email quote links
